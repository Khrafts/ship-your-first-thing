# Choose your plan

## Learning objective

By the end of this lesson, you will have picked one of this course's three tracks — Path 1, 2 or 3 — and you will be able to say, in dollars, what it costs you to run.

## Why this matters

Your computer can run any track. Now the question that decides which account you create next: what does each track cost you, in real dollars or real limits? The biggest reason learners quit a course like this is cost shock — a subscription renews for more than expected, or a free tool suddenly asks you to wait or pay. Five minutes here prevents that.

## Core read

### The honest premise

Every path costs you something — money, or limits, or both. **All three can ask you to wait on a heavy day.** You're choosing between paying a predictable monthly amount for a larger allowance, or paying nothing for a smaller one that can change without much warning. All three are honest paths, as long as you know which one you picked and why.

### Path 1 — Claude Code desktop (paid)

[Claude Code desktop](../../GLOSSARY.md#claude-code) costs **$20/month, or $17/month if you pay for a year up front.** No free plan includes it. What the $20 buys: every lesson in this course, with a usage allowance that resets on a schedule. On a heavy day the app can tell you to wait until it resets. You don't need to turn on any paid extras.

Pick Path 1 if you have $20/month you're comfortable spending on this, and you'd rather pay for a bigger, predictable allowance than manage a free one.

### Path 2 — Codex, inside the ChatGPT desktop app (free with a ChatGPT account)

[Codex](../../GLOSSARY.md#codex) is OpenAI's coding agent. You use it from inside the ChatGPT desktop app, and it is included on ChatGPT's [free tier](../../GLOSSARY.md#free-tier): no card, no subscription, $0 to start. Usage is limited, so the app may ask you to wait or offer a paid plan. You can wait and continue for free. What OpenAI includes on the free plan can change.

Pick Path 2 if $0 matters more than a bigger allowance and you're happy to use a ChatGPT account.

### Path 3 — OpenCode desktop (free, no account to start)

[OpenCode desktop](../../GLOSSARY.md#opencode-desktop) is an open-source agent app. It ships with a set of models marked **Free**, provided by OpenCode, and you can use them without creating any account. Two honest catches. First, each free model is offered "for a limited time" — the list changes, and a model you were using can disappear. Second, while a model is free, what you send it may be used to improve that model; keep anything private out of your prompts, which this course asks of you anyway. If you ever want more than the free models, OpenCode sells a $10/month plan, and it can also use a paid ChatGPT account you already have. (A paid Claude plan can't be used this way; Anthropic doesn't allow it.)

Pick Path 3 if you want $0 with no account, and you're fine with the free models changing under you.

### Side by side

| | Path 1: Claude Code desktop | Path 2: Codex in the ChatGPT app | Path 3: OpenCode desktop |
|---|---|---|---|
| Monthly cost | $20 ($17 billed yearly) | $0 to start | $0 |
| Account to create | Claude | ChatGPT | None to start |
| What can make you wait | Your allowance on a heavy day, until it resets | Your free allowance on a heavy day | A free model's own limits, or the model being withdrawn |
| Private-data note | — | — | Free models may learn from what you send |

### Switching is cheap

Nothing locks you to the path you pick today. Every lesson works the same in all three apps; switching later costs you one thing: creating the account you skipped the first time.

## Exercise

1. Reread the table above.
2. Say your path out loud, in one sentence: "I'm on Path 1", "Path 2" or "Path 3".
3. Say your path's monthly cost out loud — a number, not a shrug.
4. Write your path down somewhere you'll see it before Lesson 4.

## Checkpoint

You've got this if you can:

- Name your chosen path in one phrase.
- Say what it costs you per month, in dollars.
- Say which account Lesson 4 has you create next — Claude, ChatGPT, or none.

## What you just did

You picked a path and put a real number on it before creating a single account — knowing that any path can ask you to wait on a heavy day. Lesson 4 is the payoff: you'll create exactly the account your path needs, nothing more.
